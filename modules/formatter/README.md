# Formatter
根据任务书取的名字，因为最后这玩意儿并不执行代码而是显示一下层级检查一下语法错误然后再格式化一下就行了，相当于超级简单版本的clangd。当然这玩意儿肯定不简单。

## 架构
### 流程
基本维持我对这玩意儿的想象：
词法分析 --> 语法分析 --> AST

细化一点可能是这样：

String --> 词法分析 --> Tokens ---> 语法分析 ---> AST

关于报错，词法分析基本上也没啥可以检查的可能主要便是在语法分析阶段进行报错

然后这里可能比较complex因为 Token 必须包含行号列号 这样就便于报错了

### 词法分析
没啥可说的，直接扫描空格/字符串等等切分出token就行了， 字符串的话需要检测 "\" 换行以及 escape 一下字符。
